# zed-yukino

[Yukino](https://github.com/yukitsuri/yukino) language extension for the [Zed](https://zed.dev) editor powered by [yukino-lsp](https://github.com/yukitsuri/yukino-lsp).

Provides Tree-sitter syntax highlighting, code completion, diagnostics, and snippets.

## Installation

Ensure `yukino-lsp` is installed and available in `PATH`.

### Local Installation in Zed

1. Clone or copy this repository to your local machine.
2. Open Zed and open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
3. Select `zed: install dev extension` and choose the `zed-yukino` directory.
